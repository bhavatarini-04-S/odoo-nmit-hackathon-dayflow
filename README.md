# Dayflow

Dayflow is a premium HRMS frontend built with React 18, TypeScript, Vite, Tailwind CSS, React Router, Zustand, and shadcn/ui-compatible foundations.

## Run locally

```bash
npm install
npm run dev
```

Use any seeded employee email with the demo password `dayflow123`.

## Checks

```bash
npm run build
npm run lint
```
